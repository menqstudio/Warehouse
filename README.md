# 🏪 MenQ — Խանութի կառավարում / Store management

Ունիվերսալ web-ծրագիր **ամեն տեսակի խանութի** համար՝ պահեստ, վաճառք (POS), գնումներ,
առաքում/բաշխում, վերադարձ, ֆինանս, հաշվետվություն։ Զրո կախվածություն — միայն **Python 3** + браузер։
Տվյալները՝ SQLite (`warehouse.db`)։

Universal web app for **any kind of shop**: warehouse, sales (POS), purchases, delivery/distribution,
returns, finance, reports. Zero dependencies — just **Python 3** + a browser. Data in SQLite.

---

## 🚀 Գործարկում / Run
- **Մեկ համակարգչի վրա** → double-click **`start.bat`** (ինքը բացում ա browser-ը)։
- **Ցանցով (LAN)** → **`start-lan.bat`**. ուրիշ սարքերը նույն Wi-Fi-ով բացում են ցույց տրված հասցեն (`http://192.168.x.x:8765`)։
- Ձեռքով՝ `python app.py` (կամ `python app.py lan`), հետո՝ http://127.0.0.1:8765

## 🔐 Մուտք / Login
Բացվում ա login էջով։ 2 դեր՝
- **Տնօրեն (admin)** — ամեն ինչ։ Սկզբնական՝ `admin` / `admin`
- **Աշխատող (seller)** — **միայն Վաճառք** (չի տեսնում ինքնարժեք/ֆինանս/պահեստ)։ Սկզբնական՝ `vacharox` / `1234`

> ⚠ Առաջին բանը՝ Կարգավորումներ → Օգտատերեր-ից **փոխիր գաղտնաբառերը**։

## 🧩 Ունիվերսալ ապրանքի մոդել / Configurable products
Ապրանքն ունի պարզ միջուկ (անուն, կատեգորիա, բրենդ, մատակարար, գին, ինքնարժեք, մեծածախ, քանակ, նկար)
+ **քո սարքած դաշտերը**։ Կարգավորումներ → **Ապրանքի դաշտեր**-ից ավելացրու ինչ պետք ա՝
Չափս/Գույն (հագուստ, կոշիկ), Մոդել/Երաշխիք (տեխնիկա), Ժամկետ (մթերք)... Դատարկ թող՝ եթե պարզ խանութ ա։
Barcode՝ ավտո EAN-13 կամ սկանով։

## ✨ Ինչ կա / Features
- **Վահանակ** — KPI-ներ, 14-օրյա գրաֆիկ, թոփ ապրանքներ, ցածր մնացորդ, կասսա/պարտք/payable։
- **Պահեստ** — ապրանք ավելացնել/խմբագրել (նկարով), որոնում, **CSV import/export**, **շտրիխ-կոդով պիտակ տպել** (🏷)։
- **Վաճառք (POS)** — scan/click զամբյուղ, **բազմ-խանութ** (ընտրում ես որ locations-ից ես վաճառում), մանրածախ/մեծածախ,
  կանխիկ/ապառիկ/փոխանցում, զեղչ, հարկ, հաճախորդ+բոնուս, առաքում (առաքիչ+խանութ), **չեկ տպել**, + **Վերադարձ/refund**։
- **Գնումներ** — ապրանք ընդունել մատակարարից, **մատակարարի պարտք (payable)**, ինքնարժեքն ինքնաշխատ թարմանում ա։
- **Պարտքեր** — հաճախորդի պարտք + մատակարարի պարտք, մասնակի մարում։
- **Տեղափոխություն** — Պահեստ↔Խանութ, ամեն locations-ի մնացորդն առանձին։
- **Ֆինանս/Կասսա** — մնացորդ, հասույթ, շահույթ, զուտ, COGS, ծախս, վերադարձ; ձեռքով մուտք/ելք։
- **Հաշվետվություն** — ժամանակահատվածով, ըստ ապրանքի/խանութի/առաքիչի/վաճառողի, ստատիստիկա։
- **Կարգավորումներ** — խանութի անուն/արժույթ/հարկ/բոնուս, ապրանքի դաշտեր, master-data (կատեգորիա, բրենդ, միավոր,
  մատակարար, խանութ, առաքիչ, մեքենա, հաճախորդ), օգտատերեր, **backup (.db)**, import/export։
- **Երկլեզու** HY⇄EN (վերևի աջ անկյունում)։

## 📦 Տեղադրված exe-ով / Installed (MenQ-Setup.exe)
- Բացվում ա **Start Menu → MenQ**-ից (կամ desktop shortcut)։ Python պետք չի։
- **Տվյալները՝** `%LOCALAPPDATA%\MenQ\warehouse.db`։ Uninstall-ը **չի ջնջում** այս ֆայլը (backup-դ մնում ա)։
- **Backup/Restore.** Կարգավորումներ → Backup (.db)։ Վերականգնում՝ փակիր ծրագիրը, դիր ֆայլը վերևի պանակում որպես `warehouse.db`։
- **Փակել.** վերևի աջ ⏻ կոճակը (Տնօրեն) կանգնեցնում ա ծրագիրը։ (Browser-ի պատուհանը փակելը միայն թաքցնում ա։)
- **Ցանցով (LAN).** Start Menu → **«MenQ (LAN mode)»**. LAN-ը միանում ա **միայն admin-ի գաղտնաբառը փոխելուց հետո**. LAN հասցեն (`http://192.168.x.x:8765`) երևում ա ծրագրի վերևի կանաչ պիտակում — բացիր հեռախոսից/այլ սարքից։ Առաջին անգամ Windows-ը կարող ա հարցնի firewall-ի թույլտվություն (`Allow access`) — թույլ տուր, որ ուրիշ սարքերը տեսնեն։ Եթե non-admin ես ու pop-up չեկավ, մի անգամ admin-ից՝ `netsh advfirewall firewall add rule name="MenQ" dir=in action=allow protocol=TCP localport=8765`։
- **SmartScreen.** exe-ն ստորագրված չէ, ուստի Windows-ը կարող ա ցույց տա «Windows protected your PC» → **More info → Run anyway**։ Նորմալ ա։

## 💾 Backup / Restore (source-ից)
Կարգավորումներ → **Backup (.db)**։ Վերականգնում՝ դիր folder-ում որպես `warehouse.db`։

## 🔄 Մաքուր սկիզբ / Fresh start
Demo-ն մաքրելու համար՝ փակիր ծրագիրը, ջնջիր `warehouse.db` (installed-ի դեպքում՝ `%LOCALAPPDATA%\MenQ`-ից), նորից բացիր (կստեղծվի դատարկ բազա՝ admin/admin, vacharox/1234)։

## 🖨 Պրինտեր / Printing
Չեկն ու պիտակը տպվում են browser-ի print dialog-ով → **Windows-ին կպած ցանկացած պրինտեր** (սովորական, thermal չեկի, label)։ Label-ի չափը (mm) Կարգավորումներից. label printer-ի driver-ի թղթի չափը դիր նույնը։ Շտրիխ-կոդը իրական **Code128** ա (scanner-ը կարդում ա)։
